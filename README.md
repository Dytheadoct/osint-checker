# OSINT Checker

Простая проверка ответа для OSINT-заданий с геолокацией. Участник вводит найденные координаты, и если точка попадает в заданный радиус от эталона (по умолчанию 10 м), сервис отдаёт флаг.

Один статический Go-бинарник без зависимостей, образ в `scratch`, встроенная защита от перебора на уровне API (работает и для веб-интерфейса, и для `curl`).

## Быстрый старт

Нужны Docker или Podman с compose.

```bash
git clone <URL репозитория> osint-checker
cd osint-checker

cp .env.example .env
nano .env                       # впиши FLAG, TARGET_LAT, TARGET_LON, при желании PUBLIC_PORT

docker compose up -d --build    # или: sudo podman compose up -d --build
```

Чекер откроется на `http://localhost:<PUBLIC_PORT>` (по умолчанию 8080).

Проверка, что сервис живой:

```bash
curl -s -d 'coords=12.345678, 23.456789' http://localhost:8080/api/check
# {"ok":false,"msg":"неверно"}
```

Логи, остановка и обновление:

```bash
docker compose logs -f
docker compose down
docker compose up -d --build --force-recreate    # после правок .env или кода
```

## Настройка (`.env`)

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `FLAG` | обязательна | Флаг, который отдаётся при верном ответе |
| `TARGET_LAT`, `TARGET_LON` | обязательны | Эталонная точка, десятичные градусы |
| `RADIUS_M` | `10` | Допустимое отклонение в метрах |
| `PUBLIC_PORT` | `8080` | Порт на хосте |
| `FREE_TRIES` | `5` | Неверных попыток до первой блокировки |
| `MIN_INTERVAL` | `2s` | Минимальная пауза между попытками с одного адреса |
| `LOCK_BASE` | `30s` | Первая блокировка, дальше удваивается |
| `LOCK_MAX` | `1h` | Потолок блокировки |
| `DECAY` | `1h` | Через сколько тишины счётчик ошибок обнуляется |
| `GLOBAL_PER_MIN` | `300` | Потолок попыток в минуту на весь сервис |
| `TRUST_PROXY` | `0` | `1` только за собственным reverse proxy (см. ниже) |

Комментарии в `.env` пиши только на отдельных строках: `podman --env-file` не умеет отрезать их в конце значения.

## API

`POST /api/check` принимает координаты в любом из видов:

```bash
curl -s -H 'Content-Type: application/json' -d '{"coords":"12.345678, 23.456789"}' http://localhost:8080/api/check
curl -s -d 'coords=12.345678,23.456789' http://localhost:8080/api/check
curl -s -d '12,345678; 23,456789' http://localhost:8080/api/check
```

Порядок всегда «широта, долгота». Ответы:

| Код | Когда |
|---|---|
| `200` и `"ok":true` | точка в радиусе, в ответе `flag` |
| `200` и `"ok":false` | неверно; может прийти `retry_after`, если назначена блокировка |
| `400` | координаты не разобраны |
| `405` | не `POST` |
| `413` | тело больше 1 КБ |
| `429` | слишком частые попытки, смотри `Retry-After` |

Расстояние до цели пользователю не сообщается, чтобы нельзя было вычислить точку по ответам «горячо/холодно». Оно пишется только в лог сервера.

## Защита от перебора

- Одна попытка в `MIN_INTERVAL` с одного адреса: параллельные запросы отсекаются.
- После `FREE_TRIES` неверных ответов блокировка растёт вдвое с каждой следующей ошибкой до `LOCK_MAX`.
- Заблокированному клиенту отказывается и верный ответ: лимит проверяется до разбора координат.
- Общий потолок `GLOBAL_PER_MIN` на весь сервис.
- IPv6 считается по префиксу /64.

Если участники сидят за одним NAT, они делят общие попытки: подними `FREE_TRIES`.

## За reverse proxy (nginx, Caddy)

1. Привяжи порт к localhost в `docker-compose.yml`: `"127.0.0.1:${PUBLIC_PORT:-8080}:8080"`.
2. Включи `TRUST_PROXY=1` в `.env`. Тогда адресом клиента считается последний элемент `X-Forwarded-For`, то есть тот, что дописал твой прокси.
3. Проверь, что прокси добавляет заголовок, а не только пробрасывает клиентский. Без этого все участники будут выглядеть как один адрес и делить одни попытки.

Самому приложению TLS не нужен: терминируй его на прокси.

## Разработка

```bash
go vet ./...
go test -race ./...
```

Для запуска без контейнера задай переменные из `.env` в окружении и выполни `go run .`.

## Что хранить в секрете

В репозиторий не попадают `.env`, флаг, эталонные координаты и материалы с решением. Для запуска образ не содержит секретов: они передаются через `.env` при старте.
